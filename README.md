# Responsive Sidebar Menu

A responsive sidebar navigation menu built using HTML and CSS. The project uses a checkbox toggle mechanism to open and close the sidebar without JavaScript.

## Features

* Responsive sidebar navigation
* Pure HTML and CSS implementation
* Smooth sidebar animations
* Font Awesome icons
* Social media icon section
* Modern UI design
* Background image support

## Technologies Used

* HTML5
* CSS3
* Font Awesome
* Google Fonts (Poppins)

## Project Structure

├── index.html
├── style.css
├── photo.jpg
└── README.md

## How It Works

* The sidebar is hidden by default.
* A checkbox is used to control the sidebar state.
* Clicking the hamburger icon opens the sidebar.
* Clicking the close icon hides the sidebar.
* CSS transitions create smooth animations.
